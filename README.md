# GrassRoots A.I. SCQOS Documentation

Public documentation, specifications, onboarding material, and interoperability guidance for SCQOS.

SCQOS is concerned with governing consequential state transitions: not merely whether an AI response sounds acceptable, but whether a proposed action is admissible before a writer or other consequential mechanism is invoked.

## Public / private boundary

This repository is intentionally documentation-first. It may contain public specifications, schemas, examples, diagrams, demo instructions, and selected synthetic receipts.

It must not contain production source code, cloud account identifiers, credentials, secrets, private infrastructure details, internal deployment procedures, private operational evidence, or sensitive customer data.
