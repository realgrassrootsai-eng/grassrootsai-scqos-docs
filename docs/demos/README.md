# Demo Guidance

Public demos should make consequence governance observable.

A useful demonstration shows both paths:

- **HOLD path:** a proposal is evaluated, the writer is not invoked, and authoritative state remains unchanged.
- **PERMIT path:** the exact proposal is authorized and evaluated, the writer is invoked, and the resulting state change is verified.

Synthetic or disposable state should be used for public demonstrations. Demo receipts should avoid production identifiers, credentials, private infrastructure data, or customer information.
