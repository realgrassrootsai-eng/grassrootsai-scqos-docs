# Interoperability

This section will hold versioned public contracts for systems that exchange proposals, authority evidence, decisions, and receipts with SCQOS.

The intended model is implementation-independent: an external system may produce authority or evidence in its own architecture so long as the interoperable representation contains the information SCQOS requires to evaluate the governed event.

Planned versioned artifacts include proposal envelopes, authority envelopes, decision records, receipt structures, validation rules, and compatibility notes.
